Website-Building Process

01

Vibe Code the Basics

I do not currently know how to code, but I wanted to make a website to easily share what I have accomplished during my engineering career. So, I used Claude, Anthropic's AI agent, to vibe code the necessities for the website (styles, fonts, page files, placeholders for specific items, etc.). Once the code was generated, the site was published via GitHub pages so that I could see how my updates worked in real-time.

02

Tweak and Improve Site Pages

With the necessities in place, small changes needed to be made: putting my full name instead of just my first, adding details where Claude put placeholders, adding sections as necessary to display the correct information, etc. Some of this was as simple as typing out what I wanted a text box to say, but other times it was asking Claude for further details about how to add a specific section or how to change a layout. Most of the time this was still vibe coding, but some of the time was me asking Claude for direction but writing the code myself.

03

Complex Implementation/Future Plans

The biggest project I wanted to show off was the aero map for Flame 5, and to find a way to integrate that into the FSAE page. The aero map is not yet done, but once it is the plan is to find a way to integrate it into the site so that anyone can input a valid speed, yaw, and ride height, and see exactly how Flame 5 is projected to perform. Other than that I would also like to implement a cross-sectional interactive slideshow to see head-on how the air acts as it flows over Flame 5 and its components.
